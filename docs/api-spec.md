# Webhook API Integration Specification (2026)

This document describes the JSON payloads and webhook parameters used to communicate between your Python client applications and n8n workflow engines.

---

## 🤖 1. AI Chatbot Webhook

- **Webhook URL (Test)**: `http://localhost:5678/webhook-test/chatbot`
- **Webhook URL (Production)**: `http://localhost:5678/webhook/chatbot`
- **Method**: `POST`
- **Headers**: `Content-Type: application/json`

### Request Payload Schema
```json
{
  "message": "The user message query here",
  "provider": "openai" | "anthropic",
  "model": "gpt-4o" | "gpt-3.5-turbo" | "claude-3-5-sonnet-20241022" | "claude-3-haiku-20240307"
}
```

*Note: `provider` and `model` are optional. If not supplied, n8n defaults to `openai` and `gpt-4o`.*

### Successful Response Schema
```json
{
  "status": "success",
  "provider": "openai",
  "model": "gpt-3.5-turbo",
  "response": "Hello! I am doing well, how can I help you today?",
  "timestamp": "2026-06-03T12:00:00.000Z"
}
```

## ✍️ 2. AI Content Creator Webhook

- **Webhook URL (Test)**: `http://localhost:5678/webhook-test/content-creator`
- **Webhook URL (Production)**: `http://localhost:5678/webhook/content-creator`
- **Method**: `POST`
- **Headers**: `Content-Type: application/json`

### Request Payload Schema
```json
{
  "topic": "The title or subject matter",
  "content_type": "Blog Post" | "Social Media Post" | "Newsletter" | "Video Script" | "Marketing Copy",
  "audience": "The target reader profile (e.g. developers, founders)",
  "tone": "Professional" | "Casual" | "Informative" | "Creative" | "Persuasive"
}
```

### Successful Response Schema
```json
{
  "status": "success",
  "topic": "Python Webhooks in 2026",
  "content_type": "Blog Post",
  "outline": "### Outline of sections generated by Claude...",
  "final_content": "### Full text draft generated by OpenAI GPT in Markdown format...",
  "timestamp": "2026-06-03T12:00:05.000Z"
}
```

## 🚀 3. Command-Line Examples

### Testing Chatbot Webhook
```bash
curl -X POST http://localhost:5678/webhook/chatbot \
  -H "Content-Type: application/json" \
  -d '{"message": "Why is python great for automation?", "provider": "anthropic"}'
```

### Testing Content Creator Webhook
```bash
curl -X POST http://localhost:5678/webhook/content-creator \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "The Future of No-Code Automation",
    "content_type": "Newsletter",
    "audience": "Tech Enthusiasts",
    "tone": "Casual"
  }'
```
